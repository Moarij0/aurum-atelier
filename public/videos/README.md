# Video assets

Drop a file with the exact name below into this folder and it replaces the
placeholder automatically — no code changes needed. `.mp4` is required;
`.webm` is optional (used first if present). An optional poster image at
`{name}-poster.jpg` (or `.png`/`.webp`/`.avif`) shows while the video loads.

| File name | Used in | Notes |
|---|---|---|
| `hero.mp4` | Hero | 4K, 15-25s loop, silent, cinematic dolly. Ch.8/12 |
| `brand-story.mp4` | Brand Story | Portrait orientation works well, 10-15s loop |
| `philosophy.mp4` | Luxury Philosophy | Full-width, 15-20s loop, mood over motion |
| `service-haircut.mp4` | Signature Services | 8-12s loop |
| `service-colour.mp4` | Signature Services | 8-12s loop |
| `service-balayage.mp4` | Signature Services | 8-12s loop |
| `service-bridal.mp4` | Signature Services | 8-12s loop |
| `service-extensions.mp4` | Signature Services | 8-12s loop |
| `service-consultation.mp4` | Signature Services | 8-12s loop |
| `booking.mp4` | Booking Experience | Full-width, darkens toward the CTA |

Until a file exists, each slot renders a labeled dark placeholder at the
correct aspect ratio so layout never shifts when real footage lands.
